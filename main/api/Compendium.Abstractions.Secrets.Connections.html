Namespace Compendium.Abstractions.Secrets.Connections

Classes

SecretVaultConnection

Everything an adapter needs to reach one vault tenancy on one provider. Passed explicitly to every port method so adapters stay stateless singletons and a single adapter instance can serve many tenancies (platform-owned today, per-tenant or BYO-vault later) without contract changes.

SecretVaultCredential

The credential material of a SecretVaultConnection, as a closed union. Token-bearing members redact their material in ToString() so a logged connection never leaks a secret.

SecretVaultCredential.ApiToken

A durable API token or key (Scaleway IAM API key secret, Vault token, cloud key-vault access key).

SecretVaultCredential.None

No credential material: for in-memory and null vaults, or adapters that authenticate ambiently (workload identity, instance profile).
