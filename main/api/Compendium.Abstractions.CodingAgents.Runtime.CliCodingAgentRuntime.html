Template-method base for runtimes that drive a CLI-based coding agent (Claude Code, Codex, Cursor CLI, ...). The base orchestrates:

  1. provision the sandbox via CreateSandbox(CodingAgentRuntimeOptions) + StartAsync(SandboxOptions, CancellationToken);
  2. build the command line via BuildCommand(CodingAgentRuntimeOptions, CodingAgentRunRequest);
  3. build the environment via BuildEnvironment(CodingAgentRuntimeOptions, CodingAgentRunRequest);
  4. spawn the CLI via SpawnAndStreamLinesAsync(CliCommand, IReadOnlyDictionary<string, string>, IAgentSandbox, CancellationToken) (overridable for tests / non-process sandboxes);
  5. parse each output line via ParseStreamLine(CliStreamLine);
  6. emit a terminal CodingAgentStreamEvent.Done;
  7. dispose the sandbox.
