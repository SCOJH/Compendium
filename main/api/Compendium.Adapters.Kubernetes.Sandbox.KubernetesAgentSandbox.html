IAgentSandbox backed by an ephemeral Kubernetes pod. Each instance owns exactly one pod: StartAsync(SandboxOptions, CancellationToken) creates it and waits for Running; subsequent calls run inside it through kubectl exec-equivalent API streams; DisposeAsync() deletes the pod (best-effort) so resources are released even if the caller faulted.
