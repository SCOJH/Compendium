Enum GitCapability

Namespace
Compendium.Abstractions.Git.Capabilities
Assembly
Compendium.Abstractions.Git.dll

The optional capabilities a git-server adapter may support. Adapters declare their support level per capability in GitServerCapabilities; operations relying on an unsupported capability fail with Git.CapabilityNotSupported instead of throwing.
