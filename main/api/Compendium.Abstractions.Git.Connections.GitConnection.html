ServerUrl

Gets the API base URL for self-hosted instances — the full prefix API requests are issued against, not the web host root (GitHub Enterprise Server: https://ghes.example.com/api/v3; GitLab on-prem: https://gitlab.example.com/api/v4). null targets the provider's cloud service.
