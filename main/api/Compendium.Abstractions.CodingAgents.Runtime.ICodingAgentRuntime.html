Interface ICodingAgentRuntime

Compendium.Abstractions.CodingAgents.Runtime
Assembly
Compendium.Abstractions.CodingAgents.dll

Provides streaming execution of a coding agent. Implementations wrap a concrete engine (Claude Code, Codex, Cursor CLI, ...) and translate its output into the neutral CodingAgentStreamEvent stream.

public interface ICodingAgentRuntime

Remarks

The runtime owns the agent's lifecycle for the duration of the call: it provisions the sandbox, spawns the CLI, parses output, and tears the sandbox down before the enumeration completes. Cancellation must abort the underlying process and dispose the sandbox.

Properties

Gets the engine identifier this runtime handles (e.g. "claude-code"). Used to dispatch a run to the right adapter.
