Provider-agnostic, two-way connector to a conversational messaging platform (Telegram, Slack, Discord, Microsoft Teams, WhatsApp, or a generic webhook).

public interface IMessagingConnector

Remarks

A connector has two responsibilities: translate a raw inbound platform webhook into normalized InboundMessage values (verifying authenticity along the way), and deliver a normalized OutboundMessage back to the platform.

Credentials (bot token, signing secret, ...) are supplied per call via ChannelCredentials rather than baked into the connector, so a single registered connector can serve many tenants — the host resolves the right secret for the inbound conversation and passes it in.
