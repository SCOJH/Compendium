Inbound side of webhooks: verifies a raw delivery's signature and parses it into the neutral GitWebhookEvent union. Pure and synchronous — it owns no HTTP endpoint; the host maps its own route and hands the raw body/headers here. Requires WebhookIngestion.

public interface IGitWebhookIngestor

Methods

Parse(GitWebhookDelivery, string)

Verifies the delivery signature against secret (fail-closed: missing or invalid signatures return Git.WebhookSignatureInvalid) and parses the payload. Event types the platform does not consume parse to GitWebhookEvent.Unsupported — callers acknowledge those with a 2xx and never retry.
