Namespace Compendium.Abstractions.CodingAgents.Runtime

Classes

CliCodingAgentRuntime

Template-method base for runtimes that drive a CLI-based coding agent (Claude Code, Codex, Cursor CLI, ...). The base orchestrates:

  1. provision the sandbox via CreateSandbox(CodingAgentRuntimeOptions) + StartAsync(SandboxOptions, CancellationToken);
  2. build the command line via BuildCommand(CodingAgentRuntimeOptions, CodingAgentRunRequest);
  3. build the environment via BuildEnvironment(CodingAgentRuntimeOptions, CodingAgentRunRequest);
  4. spawn the CLI via SpawnAndStreamLinesAsync(CliCommand, IReadOnlyDictionary<string, string>, IAgentSandbox, CancellationToken) (overridable for tests / non-process sandboxes);
  5. parse each output line via ParseStreamLine(CliStreamLine);
  6. emit a terminal CodingAgentStreamEvent.Done;
  7. dispose the sandbox.
CliCommand

A resolved CLI invocation: the executable to run and the argument vector. Used by CliCodingAgentRuntime as the output of BuildCommand(CodingAgentRuntimeOptions, CodingAgentRunRequest).

CodingAgentRunRequest

The per-invocation input to RunAsync(CodingAgentRuntimeOptions, CodingAgentRunRequest, CancellationToken): the prompt to give the agent and any optional metadata for tracing, resumption, and tenant scoping.

CodingAgentRuntimeOptions

Configures a single coding-agent run: which engine to use, where it runs, what skills/MCP servers are mounted, and how it authenticates.

Structs

CliStreamLine

A single line read from a spawned CLI's output, tagged with the stream it came from. Passed to ParseStreamLine(CliStreamLine) so adapters can decide how to translate stdout vs. stderr.

Interfaces

ICodingAgentRuntime

Provides streaming execution of a coding agent. Implementations wrap a concrete engine (Claude Code, Codex, Cursor CLI, ...) and translate its output into the neutral CodingAgentStreamEvent stream.
