Compendium.Adapters.Kubernetes.Sandbox

Adapter-level defaults for KubernetesAgentSandbox. These are the values used when the per-run SandboxOptions does not override them, and the values that govern adapter behavior that is not represented on the neutral port (RBAC service account, resource limits, network policy, PVC).

Remarks

All quantities are CPU/memory strings in the standard Kubernetes resource format (500m, 1Gi, ...). Validation is deferred to the API server.
