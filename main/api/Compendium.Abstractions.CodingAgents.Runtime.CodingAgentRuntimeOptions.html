Remarks

The shape is deliberately neutral: Engine identifies the adapter ("claude-code", "codex", "cursor", ...) and Parameters is the bag of adapter-specific knobs. Cross-cutting concerns (sandbox, skills, auth) are first-class so the host can apply uniform policy regardless of vendor.

Properties

Auth

Gets the authentication material for the engine (API keys, OAuth tokens, ...). Names are adapter-specific (e.g. "ANTHROPIC_API_KEY"). Values are treated as secrets — the abstraction layer never logs them.
