Class InMemoryGitServer

Namespace
Compendium.Testing.Git
Assembly
Compendium.Testing.dll

Full-fidelity in-memory IGitServer fake for tests and dev mode. Declares every capability as Full and keeps all state in memory: repositories created from templates, secret NAMES (values are discarded — mirroring the write-only semantics of real providers), variables, deployment environments, branch policies, teams, webhook subscriptions, and pipeline runs.

public sealed class InMemoryGitServer : IGitServer, IGitCredentialBroker, IGitRepositoryService, IGitPipelineService, IGitCiConfigurationService, IGitEnvironmentService, IGitBranchPolicyService, IGitAccessControlService, IGitWebhookService, IGitWebhookIngestor, IGitNamespaceProvisioner

Remarks

Thread-safe. Test hooks: SeedInstallation(GitInstallationInfo), SeedRepository(GitRepositoryRef, bool), SeedFile(GitRepositoryRef, string), CompleteRun(string, GitPipelineStatus), and the Calls log. Inbound webhook deliveries are parsed from a simple JSON envelope signed by equality with the shared secret via the X-InMemory-Signature header (fail-closed).

Remarks

Some providers do not return a run identifier on trigger (GitHub's workflow_dispatch is fire-and-forget): the handle's RunId is null there and callers correlate via ListRunsAsync(GitConnection, GitRepositoryRef, ListGitPipelineRuns, CancellationToken). Each adapter documents this in its CAPABILITIES.md.
