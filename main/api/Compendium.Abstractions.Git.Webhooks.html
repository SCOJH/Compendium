Namespace Compendium.Abstractions.Git.Webhooks

Classes

EnsureGitWebhook

Request to create or update a webhook subscription.

GitWebhookDelivery

A raw inbound webhook delivery as received over HTTP.

GitWebhookEvent

A neutral, provider-agnostic inbound webhook event, as a closed union for exhaustive pattern matching.

GitWebhookEvent.ConnectionChanged

The platform app's installation on an account changed (installed, suspended, unsuspended, repositories added/removed, or uninstalled).

GitWebhookEvent.PipelineRunCompleted

A pipeline run reached a terminal state.

GitWebhookEvent.PullRequestChanged

A pull/merge request changed state.

GitWebhookEvent.Push

Commits were pushed to a branch.

GitWebhookEvent.TagPushed

A tag was pushed.

GitWebhookEvent.Unsupported

An event type the platform does not consume. Acknowledge with a 2xx and do not retry.

GitWebhookSubscription

A webhook subscription as reported by the provider.

GitWebhookTarget

Where a webhook subscription lives, as a closed union.

GitWebhookTarget.Namespace

A namespace-level (organization/group) webhook.

GitWebhookTarget.Repository

A repository-level webhook.

Interfaces

IGitWebhookIngestor

Inbound side of webhooks: verifies a raw delivery's signature and parses it into the neutral GitWebhookEvent union. Pure and synchronous — it owns no HTTP endpoint; the host maps its own route and hands the raw body/headers here. Requires WebhookIngestion.

IGitWebhookService

Outgoing webhook subscription management on a repository or namespace. Requires WebhookManagement.
