Interface IIdempotencyReservationStore

Namespace
Compendium.Application.Idempotency

An IIdempotencyStore that can also reserve a key atomically, so that two concurrent callers presenting the same key cannot both run the operation.

public interface IIdempotencyReservationStore : IIdempotencyStore

Remarks

A separate contract rather than a new member on IIdempotencyStore: adding a member would break every existing implementation, and a default implementation built on ExistsAsync(string, CancellationToken) then SetAsync<TValue>(string, TValue, TimeSpan, CancellationToken) could not be atomic — which is the whole point.
