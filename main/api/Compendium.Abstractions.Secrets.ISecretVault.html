Interface ISecretVault

Namespace
Compendium.Abstractions.Secrets
Assembly
Compendium.Abstractions.Secrets.dll

The secret-vault facade: one instance per provider adapter, carrying the provider discriminator, the declarative capability matrix, and the concern-scoped ports. Consumers resolve IEnumerable<ISecretVault> and dispatch on Provider (the sub-ports are also registered individually for single-concern consumers).

public interface ISecretVault

Remarks

Implementations are stateless singletons: all tenancy state travels in the SecretVaultConnection passed to every method, so a single adapter instance serves any number of tenancies concurrently.
