Namespace Compendium.Abstractions.Git.Connections

Classes

GitAccessToken

A ready-to-use, short-lived token minted for a GitConnection. Usable against the provider's API and for git-over-HTTPS via HttpBasicUsername.

GitAccessTokenScope

Optional narrowing applied when minting a token (GitHub: repository_ids — at most 500 — plus a permissions subset). Providers without token scoping ignore the request; they declare ScopedTokenMinting as unsupported.

GitConnection

Identifies which git server to talk to and with what credential. Every port method takes a connection explicitly — ports are stateless singletons and a single adapter instance serves any number of tenants.

GitConnectionIdentity

The identity behind a validated credential.

GitCredential

The credential material of a GitConnection, as a closed union. Token-bearing members redact their material in ToString() so a logged connection never leaks a secret.

GitCredential.AppInstallation

A platform-owned app installed on the customer namespace (GitHub App installation). The adapter mints short-lived tokens from the app's private key; no durable secret is stored per connection.

GitCredential.OAuthAccessToken

An OAuth user access token (user-to-server), used to act as — or verify the identity of — a specific human.

GitCredential.PersonalAccessToken

A caller-supplied user personal access token, held in memory for the duration of the call only — never persisted, logged, or cached.

GitCredential.ServiceAccountToken

A durable machine token (GitLab group access token, Gitea/Forgejo bot PAT, Azure DevOps service principal secret).

GitInstallationInfo

A platform-app installation on a customer account.

Interfaces

IGitCredentialBroker

Mints, validates, and discovers credentials for git connections. This is the auth seam of the abstraction: app-installation providers (GitHub) mint ephemeral installation tokens from the platform app's private key, while token-based providers (GitLab, Gitea) wrap the connection's durable token.

Enums

GitAccountType

The kind of account a namespace or credential identity refers to.
