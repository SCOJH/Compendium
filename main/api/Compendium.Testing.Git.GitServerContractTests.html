The behavioral contract every IGitServer adapter must satisfy. Inherit in the adapter's test suite and provide the fixture members; tests for capabilities the adapter does not declare are skipped automatically (capability honesty is itself asserted: a declared capability must work). InMemoryGitServer subscribes to this contract, keeping the fake and real adapters aligned.
