Interface IGitCredentialBroker

Namespace
Compendium.Abstractions.Git.Connections
Assembly
Compendium.Abstractions.Git.dll

Mints, validates, and discovers credentials for git connections. This is the auth seam of the abstraction: app-installation providers (GitHub) mint ephemeral installation tokens from the platform app's private key, while token-based providers (GitLab, Gitea) wrap the connection's durable token.

ResolveAppInstallationByIdAsync(string, string?, CancellationToken)

App-installation mode only: resolves a single installation of the platform app by its provider-side id. Unlike ResolveAppInstallationAsync(string, string?, CancellationToken) (which probes by account) and ListAppInstallationsAsync(string?, CancellationToken) (which pages the whole list), this is an O(1) point lookup — use it when a caller already holds an installation id and only needs to confirm it still belongs to the app. Fails with Git.InstallationNotFound when the id does not belong to the app (never installed, or the installation was deleted).
