Interface IWebhookSender

Namespace
Compendium.Abstractions.Webhooks
Assembly
Compendium.Abstractions.Webhooks.dll

Provides operations for fan-out of integration events to external consumer endpoints. This port complements the in-process outbox: where the outbox publishes integration events inside the application, an IWebhookSender adapter dispatches them over HTTP to subscribed external endpoints with provider-managed retries and signatures. Implementations may target managed services such as Svix or implement raw HTTP fan-out.
