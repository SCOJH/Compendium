Class InMemorySecretVault

Namespace
Compendium.Testing.Secrets
Assembly
Compendium.Testing.dll

A full-fidelity in-memory ISecretVault for tests and dev hosts: immutable monotonic revisions, enable/disable/destroy semantics, path-prefix listing and tag filters, thread-safe, with a call log for interaction assertions. Subscribes to SecretVaultContractTests so the fake and real adapters stay behaviorally aligned.
